# Project agents

This directory contains focused, repository-local skills for Coursemap:

- `$coursemap-ui` for accessible product and component work
- `$supabase-change` for schema, auth, RLS and generated types
- `$catalogue-import` for source-backed ANU catalogue ingestion
- `$verify-coursemap` for the repository quality gate

The root `AGENTS.md` provides the default project rules. Skills add a repeatable workflow when their subject is in scope.
